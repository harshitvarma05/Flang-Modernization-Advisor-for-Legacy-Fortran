# Real Case Study: Netlib MINPACK subset

This directory contains a small public legacy Fortran subset from Netlib MINPACK.

Source: https://netlib.org/minpack/

Files included:
- hybrd.f
- hybrd1.f
- fdjac1.f
- dogleg.f
- qform.f
- qrfac.f
- enorm.f
- r1mpyq.f
- r1updt.f
- dpmpar.f

The subset is intentionally small enough for a lab demo while still being a real external legacy Fortran codebase rather than a handcrafted fixture.
